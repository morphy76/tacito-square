# Milestone M6.5: Agent Consolidation in Communities

| Field      | Value |
|------------|-------|
| Status     | ⏳ IN_PROGRESS |

## Goal

Consolidate agents as fully-configured runtime units within communities. Define and implement all supporting entities (LLM bindings, prompts/promptsets, skills/skillsets, MCP clients), establish role as a community-assignment behavior (not an agent property), specify the full agent environment setup pipeline driven by the Operator reconciler, formalize the dynamic system prompt construction pipeline, and enrich A2A agent cards so hubs can leverage them for intelligent delegation.

## Deliverable

An agent is created with a brain bound to an LLM binding, a curated set of prompts, procedural skills, and MCP clients. It is assigned to a community, receiving a role (standalone/hub/spoke) determined by topology. The Operator reconciler materializes the full runtime environment. The hub agent reads enriched agent cards and uses its own routing skills to delegate to spokes. Supporting entity changes mark the agent as stale; a redeploy picks up fresh state.
