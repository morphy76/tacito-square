## Context

Implement dynamic templating for system and user prompts before sending them to LLM brains.

## Specification

1. Support placeholder rendering (e.g. Go template syntax) in prompt templates.
2. Inject thread context, user metadata, and agent properties into the template context.
3. Verify output formatting and escape options.
